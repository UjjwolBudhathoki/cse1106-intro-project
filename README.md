# Project Title
Basic Calculator

## Description
This is a basic calculator app which does the basic calculations which includes addition and subtraction of two integers.

##Technologies
This app uses python as a programming language for the logic part.

## How to run
Clone the code and run it in any code editor which is capable of running the python language, such as VS code.

## What I learned
From this calculator app i learned the basic of the data types and how to take input and perform the conditional check using if/else.

## Future Improvements
As of now the app is limited to the addition and subtraction. In the future the functionality can be expanded to division and multiplication.
